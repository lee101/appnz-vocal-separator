# Third-party software and models

- [Demucs](https://github.com/facebookresearch/demucs), MIT, provides Hybrid
  Transformer source separation and the pretrained `htdemucs` weights.
- [PyTorch](https://github.com/pytorch/pytorch), BSD-style, provides inference.
- FFmpeg is installed from Ubuntu packages and used for compressed outputs.
- [Cog](https://github.com/replicate/cog), Apache-2.0, provides the container
  build and prediction runtime.
